# 后端框架资料库

本目录收录后端语言与框架的选型对比、学习路径与工程实践。

## 文件清单

| 文件 | 内容 |
|---|---|
| 主流后端框架对比.md | 5 种语言 × 主流框架的横向对比与选型决策表 |
| 工程化与项目结构.md | 分层结构、错误处理、日志、配置管理、测试 |
| 接口设计与规范.md | REST 约定、统一响应结构、错误码、分页、鉴权 |

## 与主资料库的关系

- 主资料库 `../资料库/` 偏「选型卡片」与「上手要点」
- 本目录偏「落地时的工程细节」，适合进入编码阶段后查阅

## 快速判断：我该用哪个后端框架

| 你的情况 | 建议 |
|---|---|
| 一个人做全栈，已会 JS | NestJS 或 Express（TypeScript） |
| 要做 AI / 数据处理 | FastAPI（Python） |
| 学校课程要求 / 想进大厂 | Spring Boot（Java） |
| 要高并发、想学云原生 | Gin（Go） |
| 追求极致性能、不计学习成本 | Actix-Web（Rust） |

详细依据见 `主流后端框架对比.md`。
