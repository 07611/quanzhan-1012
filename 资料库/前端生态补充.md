# 前端生态补充知识

## 状态管理（主流卡片之外的备选）

| 方案 | 适用 | 特点 |
|---|---|---|
| Zustand | React | 极简，3KB，无样板代码，现在最流行 |
| Redux Toolkit | React 大型项目 | 官方推荐写法，解决老 Redux 啰嗦问题 |
| Pinia | Vue | Vue 官方推荐，替代 Vuex |
| Jotai | React | 原子化状态，适合细粒度更新 |
| Context 自带 | 小项目 | 免费，但频繁更新会引发重渲染 |

## 路由

- React：React Router（事实标准）、Next.js 自带文件路由
- Vue：Vue Router
- 纯 SPA：用 Vite + React Router / Vue Router

## 构建工具

| 工具 | 特点 |
|---|---|
| Vite | 现在默认选择，秒级冷启动，基于 esbuild/Rollup |
| Webpack | 老项目主流，配置复杂，生态最全 |
| Turbopack | Next.js 16 默认，Vite 的竞品 |
| esbuild | Go 写的，极速，常被嵌进其他工具 |

## UI 库备选（除卡片上的四种）

- **MUI (Material UI)**：React 生态老牌，Material Design 风格
- **Chakra UI**：React，可访问性好，主题化简单
- **Bootstrap**：老牌万能，学习快但审美老旧
- **Vuetify**：Vue + Material Design
- **Naive UI**：Vue 3 原生，TS 友好，国内开源
- **shadcn/ui**：不是组件库而是"复制代码"模式，Tailwind 风格，现在最流行

## 其他值得知道

- **TypeScript**：新项目基本都该用，类型能挡掉一半 bug
- **ESLint + Prettier**：代码规范标配
- **pnpm**：比 npm/yarn 快、省磁盘，现在推荐
