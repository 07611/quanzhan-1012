# 全栈技术资料库索引

本目录是「FullStack Architect 全栈架构工作台」的配套资料库，也是独立的离线知识集。
工作台的「知识库」视图已内置这些内容的核心条目，可在线搜索；本目录提供完整版与可离线阅读的 Markdown。

## 使用方式

### 方式一：用工作台（推荐）

1. 双击打开根目录的 `FullStack-Architect.html`
2. 「架构工作台」：填一句话想法 → 一键生成五层架构 + 完美提示词
3. 「知识库」：搜索或按类别浏览本目录的内容
4. 需要真实 AI 对话时：双击 `启动代理.bat`，再在「模型设置」里填一次 API Key

### 方式二：直接阅读

按上表打开对应 Markdown 文件即可，均为离线可用。

## 内容维护约定

- 一篇文件聚焦一个主题，标题用「名词 + 补充 / 要点 / 清单」结尾
- 对比类内容优先用表格，便于扫读
- 涉及「坑」的内容必须写清**触发条件 + 后果 + 正确做法**
- 新增文件后同步更新本索引
