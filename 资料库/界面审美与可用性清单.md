# 界面审美与可用性清单

> 针对「功能都做了，但页面看起来很廉价」这一高频问题。本文把「好看」拆成可执行、可检查的条目。

## 一、页面显廉价的六个原因（按影响排序）

| # | 症状 | 根因 | 处方 |
|---|---|---|---|
| 1 | 看不出重点，像后台模板 | 字号层级太平 | 用 **2 倍以上**的跳跃建层级 |
| 2 | 像 2010 年的网站 | 用了系统默认字体 | 换有辨识度的字体配对 |
| 3 | 平、闷、没纵深 | 纯白 / 纯灰平铺背景 | 加暖色调底 + 网格纹理 / 径向光晕 |
| 4 | 花但俗气 | 颜色没有主次 | 遵循 **70-20-10** |
| 5 | 用起来「涩」 | 交互无反馈 | hover / active / focus / disabled 四态 + 加载态 |
| 6 | 挤、喘不过气 | 留白不足 | 区块 ≥ 28–40px，卡片内边距 ≥ 16–20px |

## 二、排版

### 字体配对（禁止 Inter / Roboto / Arial / Open Sans）

| 用途 | 推荐 | 特点 |
|---|---|---|
| 标题 / 展示 | Space Grotesk、Sora、Outfit、Bricolage Grotesque | 几何感、有特征 |
| 正文 | Manrope、Inter Tight、Public Sans | 高可读、中性 |
| 中文 | Noto Sans SC、Noto Serif SC、霞鹜文楷 | 与西文搭配自然 |
| 代码 | JetBrains Mono、IBM Plex Mono | 等宽、易读 |

> 只选 **2–3 款**。字体越多越乱。

### 字号层级（戏剧化跳跃）

| 层级 | 字号 | 行高 |
|---|---|---|
| 主标题（Hero） | 36–50px | 1.08–1.15 |
| 区块标题 | 21–27px | 1.2 |
| 卡片标题 | 15–17px | 1.3 |
| 正文 | **16–17px** | 1.6–1.7 |
| 辅助文字 | 12.5–13.5px | 1.5 |
| 微标签 / 代码 | 11–12px（等宽） | 1.4 |

> 中文正文不要小于 16px，14px 在 1080p 屏幕上会显得拥挤。

## 三、色彩

### 70-20-10 比例

- **70% 中性**：背景、文字、边框
- **20% 结构色**：导航、次级按钮、图标
- **10% 强调色**：主 CTA、关键状态、唯一需要点击的地方

> 强调色出现超过三处，就失去了「强调」的意义。

### 语义化 CSS 变量（明暗双主题一次搞定）

```css
:root{
  --paper:#F5F3EE; --surface:#FFFFFF; --line:#E4E0D6;
  --ink:#17171C; --ink-2:#4B4B56; --ink-3:#8A8A97;
  --brand:#4F3FD6; --brand-tint:#EDEAFB;
  --flame:#FF5A2C; --ok:#25785F; --warn:#A9700F; --bad:#C13C3C;
}
[data-theme="dark"]{
  --paper:#131317; --surface:#1B1B21; --line:#303039;
  --ink:#F4F3EF; --ink-2:#B9B8B2; --ink-3:#8A8A93;
  --brand:#8C7EFF; --brand-tint:#262346;
}
```

**规则**：组件里只写 `var(--ink)`，绝不写 `#17171C`。这样切换主题只需改一组变量。

### 营造纵深的三种手法

1. **网格纹理**：`radial-gradient(circle at 1px 1px, rgba(0,0,0,.06) 1px, transparent 0)` + `background-size:26px 26px`
2. **径向光晕**：`radial-gradient(circle, rgba(79,63,214,.2), transparent 66%)` + `filter:blur(30px)`
3. **层级阴影**：卡片用细边框 + 极浅阴影，hover 时提升一档

```css
--sh-1:0 1px 2px rgba(38,32,18,.05),0 1px 3px rgba(38,32,18,.04);
--sh-2:0 4px 14px rgba(38,32,18,.07),0 2px 4px rgba(38,32,18,.04);
```

## 四、交互反馈（异步三态）

| 状态 | 必须有的表现 |
|---|---|
| 加载中 | 骨架屏或 spinner；超过 1 秒必须有 |
| 成功 | 短暂提示（toast / 内联反馈），1.5–2.5 秒消失 |
| 失败 | **保留用户输入**，只高亮错误字段 + 给出可读原因 |

**绝对不要**：出错时清空表单。这是最让人恼火的体验缺陷。

### 按钮四态

```css
.btn{transition:all .15s}
.btn:hover{border-color:var(--brand);box-shadow:var(--sh-2)}
.btn:active{transform:translateY(1px)}
.btn[disabled]{opacity:.45;cursor:not-allowed;box-shadow:none}
```

## 五、无障碍底线（不可妥协）

| 项 | 要求 |
|---|---|
| 正文对比度 | ≥ 4.5:1 |
| UI 元件 / 大字号 | ≥ 3:1 |
| 触摸目标 | ≥ 44×44px，间距 ≥ 8px |
| 键盘焦点 | 必须可见，`:focus-visible` 统一描边 |
| 语义标签 | `nav / main / section / article / button` |
| 动效 | 尊重 `prefers-reduced-motion` |
| 图片 | 给 `width/height` 或 `aspect-ratio` 防布局抖动 |

```css
:focus-visible{outline:2.5px solid var(--flame);outline-offset:2px;border-radius:6px}
@media(prefers-reduced-motion:reduce){
  *{animation-duration:.001ms!important;transition-duration:.001ms!important}
}
```

## 六、响应式

**移动优先**，从窄到宽增强：

| 断点 | 处理 |
|---|---|
| ≤ 640px | 所有栅格塌缩为单列；侧栏转抽屉；表格转卡片 |
| ≤ 900px | 侧边导航收起为汉堡菜单 |
| ≤ 1080px | 双栏布局转单栏 |
| ≥ 900px | 恢复多列栅格 |

必查项：
- [ ] 375px 宽下无横向滚动
- [ ] 触摸目标 ≥ 44px
- [ ] 弹窗在小屏改为底部抽屉
- [ ] 长英文串 / URL 能换行（`word-break`）

---

## 七、交付前视觉自查清单

- [ ] 字体有辨识度，不是系统默认
- [ ] 字号层级有 2 倍以上跳跃
- [ ] 背景不是纯白 / 纯灰，有纹理或光晕
- [ ] 颜色符合 70-20-10，强调色 ≤ 3 处
- [ ] 每个交互元素有 hover / active / focus 三态
- [ ] 异步操作有加载态与错误态，错误保留输入
- [ ] 375px 下无横向滚动
- [ ] 正文对比度抽测 ≥ 4.5:1
- [ ] 有明暗两套主题（或至少语义化变量）
- [ ] 页面有**一个**让人记住的设计点（不是十个小装饰）
