# 后端框架补充知识

## JVM 生态备选（卡片上只有 Spring Boot / Quarkus）

| 框架 | 特点 | 什么时候用 |
|---|---|---|
| Micronaut | 编译期依赖注入，启动快、内存低 | Serverless、GraalVM 原生镜像 |
| Vert.x | 响应式、事件驱动 | 高并发实时通信 |
| Helidon | Oracle 出品，微服务友好 | 跟 Oracle 生态绑定的企业 |
| Dropwizard | 老牌瘦包，一个 jar 跑起来 | 简单微服务 |

## Python 生态备选

| 框架 | 特点 |
|---|---|
| Litestar | 基于 ASGI，比 FastAPI 更快，类型严格 |
| Tornado | 老牌异步，长轮询/WebSocket |
| Pyramid | 灵活，从简单到复杂都能撑 |
| Blacksheep | 轻量 ASGI，FastAPI 的轻量替代 |

## Go 生态备选

| 框架 | 特点 |
|---|---|
| Chi | 轻量路由库，不像框架更像工具 |
| Echo | 卡片上有，功能均衡 |
| Gin | 卡片上有，最流行 |
| Fiber | 卡片上有，fasthttp 极速 |
| Hertz | 字节开源，高性能，国内大厂在用 |

## Rust 生态备选

| 框架 | 特点 |
|---|---|
| Actix Web | 卡片上有，性能顶尖 |
| Axum | 卡片上有，Tokio 官方 |
| Rocket | 老牌，易用性好 |
| Warp | 过滤器风格，组合式 |

## Node 生态补充

- **Midway**：蚂蚁开源，企业级 TS 框架，国内后端常用
- **Egg.js**：阿里开源，基于 Koa，约定优于配置
- **Hono**：超轻量，边缘计算/Web Worker 友好，新兴流行

## API 协议对比

| 协议 | 数据格式 | 性能 | 适用 |
|---|---|---|---|
| REST | JSON | 通用 | 90% 项目 |
| GraphQL | JSON | 灵活但复杂 | 前端需要按需取数 |
| gRPC | 二进制 Protobuf | 最高 | 微服务内部、多语言通信 |
| tRPC | 类型安全 | 开发体验好 | 前后端同 TS 项目 |
| WebSocket | 长连接 | 实时 | 聊天、通知、协作 |
| SSE | 文本流 | 轻量 | 服务端推送（AI 流式输出常用） |
